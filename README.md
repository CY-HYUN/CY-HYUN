## Selected work

**[SemEval 2026 Task 2 — emotion prediction](https://github.com/CY-HYUN/Deep-Learning-project-SemEval-2026-Task-2)**
User-level embeddings + RoBERTa ensemble for longitudinal affect prediction. CCC 0.6554 (measured best single model, +5.7% over the 0.62 target baseline). Full ablations of user embeddings vs features vs BiLSTM.

**[Synthetic-Instruction-Tuner](https://github.com/CY-HYUN/Synthetic-Instruction-Tuner)**
Zero-cost LLM fine-tuning pipeline: Magpie synthetic data generation → multi-dimensional quality filtering → LoRA (12.16M trainable parameters, 4-bit) → DPO alignment. +9.7% over the base model on a mixed benchmark.

**[QoE prediction — with an honest leakage analysis](https://github.com/CY-HYUN/Poqemon-QoE-Dataset-master)**
Mobile-streaming quality prediction where the headline is the integrity work: quantified a 33.3-point data-leakage gap (81.6% with leaky features vs 48.2% objective-only, class-balanced) and reported the honest number instead of the inflated one.

**[DEFT — defense export analysis](https://github.com/CY-HYUN/Global-Defense-Export-Analysis-Project)**
Multi-source ETL and analysis (World Bank API, SIPRI, UCDP): 102,321 records across 170 countries, clustering + regression for market feasibility scoring.
